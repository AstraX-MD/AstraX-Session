> ➪ 1. ABOUT ASTRAX

**AstraX** ni Session Generator ya WhatsApp Bot iliyojengwa na Baileys. Inakuwezesha kupata Session ID yako ndani ya sekunde 30 kwa kutumia QR Code au Pairing Code.
